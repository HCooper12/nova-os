The Line

One widget, one job: hold a single line worth carrying through the day. While the daily review has a line waiting, it is that line, in the speaker’s own words. Once the review is done, it is a line from his library.

Through a day

The same widget at each point. A tap anywhere opens the review on that line.

When things are not ideal

Each of these says what is true and still looks like the same object.

How a line fits

The type steps down for a longer line and never cuts one short. A line too long for the small size shows its idea and waits to be opened.

Large, and the lock screen

The large size has room for the idea behind the line and for today’s path. The lock screen takes the system’s single tint, so it carries the words alone.

What gets built, once approved

Real words only
Every line is the speaker’s own, found by code in his vault and checked against the transcript. Nova never writes one.
The time is proof
The timecode shows only when the transcript gives it. No time, no stamp.
Speaker unknown
When the vault cannot settle who spoke, the widget names the show and stops there.
Reading is not reviewing
The widget only reads. Showing a line on the home screen never marks it as seen in the review.
A new line daily
With nothing due, the library line changes at midnight and holds all day, chosen by the date so every size agrees.
Sizes
