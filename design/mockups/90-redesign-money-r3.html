What round 3 adds

  • Last month, same dayThe tile said “−5%”; now the pace card can draw September beside October and say which category made the difference.
  • A line’s own sheetToday a row can only be recategorised or deleted; this gives it a category with Undo, a split, a note, and the merchant rule said aloud.
  • How sure each bill isA predicted date reads as fact unless it says how regular the charge has been.
  • Billroo, end to endRound 2 drew the path as a diagram; this acts out the file, the lines, the yes and the Undo.
  • If the file is .xlsxToday Nova would say nothing and the file would sit unread.
  • The Mac at 1280Round 2 was a phone column; the Mac has room to keep the month, the budgets and the lines in view at once.
  • Stash · ReaderA reading link is for reading; it opens in Nova as a calm page with your place kept.
  • Stash · SortLinks you actually use rise to the top of their shelf.
  • Stash · Share sheetMost links are found in Safari; saving one should not mean copying and switching apps.

Your calls

  1. Reading Billroo’s .xlsxIf yes, Nova learns to read an .xlsx file in Money/Imports (a small server change and one file-format reader), and the .xlsx frame never appears: the file goes straight to the Import sheet. If no, Nova says what the .xlsx frame shows, and you re-save each export as CSV in Numbers before it is read. Worth deciding only once you have exported one file and we know which it is.
  2. Whose categories win on an importCarried from round 2 if still open. If Billroo’s, Nova reads its Category column and maps your names onto Nova’s own categories, shown on every line in the Import sheet, so a line you filed there arrives filed the same way. If Nova’s, the column is ignored and each line is guessed from the merchant, as today.
  3. Splitting a lineIf yes, a line can be split across two categories in its sheet, budgets count each part, and the FY export writes one row per part. If no, a line keeps one category and the sheet has no Split button.
  4. Saying the merchant rule out loudIf yes, changing a line’s category asks whether every line from that merchant should follow (off unless you turn it on). If no, it stays as today: the change silently applies to every future line from that merchant.
  5. Showing how sure each bill isIf yes, every predicted charge carries Sure, Likely or A guess, its dots, and a window on the calendar when it wanders; this needs new arithmetic over every past gap. If no, the calendar stays as round 2 and every predicted date looks equally certain.
  6. What the pace card opens onIf Budget pace, round 2’s view stays first and Last month is one tap. If Last month, September’s line and the serif sentence greet you each visit, and the budget pace is the tap.
  7. The Mac in three columnsIf yes, the Mac shows the month, budgets and lines side by side, and a line opens in the right-hand pane instead of a sheet. If no, the Mac shows the phone’s single column, centred, as Money does today.
  8. Stash fetching a page to readIf yes, Nova’s server fetches a saved reading link once, keeps its text in server/data, and the Reader shows it; pages it cannot read say so and open the original. If no, Stash keeps opening the original site and makes no web requests, as today.
  9. A Shortcut for the share sheetIf yes, I write the Shortcut and its steps (it posts to the same address the add bar uses, over your tailnet, and Nova picks the shelf from the site). If no, links still come in by paste and the clipboard offer from mockup 88.
  10. Stash’s default orderIf Last opened, the links you use sit first on each shelf, which needs Nova to note each open (kept in server/data; Stash.md is unchanged). If Added, the order stays as today and the sort menu offers the others.
