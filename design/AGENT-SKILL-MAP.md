# The Nova Skill Map — maximising the agents (30 July 2026)

From Hayden's shared reel (alassafi.ai): *"137 jobs AI can actually do,
grouped into the 7 departments every company runs on… what ties it together
is the first node: one company brain, loaded once, so every agent
downstream stops guessing."*

Nova is a life-OS, not a business — but the idea transfers cleanly, and
half of it is already built.

## What Nova already has (the reel's two pillars, verified)

**The one brain, loaded once.** The vault is the source of truth, and every
agent draws from the SAME deterministic context builders: NOVA_LENS (the
shared reasoning doctrine), profileContext, preferencesContext (observed
tendencies), standingContext (explicit rules — "correct once, written
down"), and the composed dispatches. This is exactly "every agent
downstream stops guessing," and it is why a new Nova agent costs so little
to add: the brain is a prepared meal, not a scavenger hunt.

**Named agents with real jobs.** The ops fleet (15 today) each own a
domain-shaped job with receipts. What Nova does NOT yet have is the reel's
real insight: the jobs mapped out EXPLICITLY — what each agent can do
today, at what autonomy, and what it could learn next — as a living
artifact rather than tribal knowledge in code and docs.

## The build this suggests (in order)

1. **The skill registry as a real artifact** — `Wiki/Library/Nova Skills.md`:
   one line per skill under department headings, each with its surface and
   autonomy level (observe / propose / act-on-approval). Written by us,
   readable by Hayden, and LOADED INTO THE AGENTS' CONTEXTS so Nova can
   answer "what can you actually do?" truthfully and per-domain — and say
   plainly what it can't do yet. (Small; high leverage; the reel's map, but
   honest.)
2. **The map drawn** — the Ops fleet ring gains department grouping and a
   tap-through: tap an agent → its skills from the registry + its recent
   receipts from the stream. The reel's zoomable universe, powered by real
   files.
3. **Skill proposals** — the learning loop closes: when an agent notices a
   repeated manual pattern ("you've logged 4 restaurant meals this month"),
   it may PROPOSE adding a skill from the backlog — riding the same pending
   rails as everything else. Autonomy stays earned and proposed.
4. **The 137-jobs equivalent** — the backlog column above, maintained as
   part of the registry file, so every future build starts from the map
   instead of a blank page.

Doctrine check: the registry is deterministic text loaded into contexts
(models decide, code acts); it lives in the vault (source of truth); skills
list their autonomy level explicitly (earned, never assumed).
