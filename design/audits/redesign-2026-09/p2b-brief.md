## The Edit sheet (`PinnedEditSheet.jsx`) — "smooth to drag around and edit with no lag" (his words)
- Mounted by MissionSummary when `S.edit.open`. Markup: backdrop `role="dialog" aria-modal="true" aria-label="Edit Pinned"` `position:fixed; inset:0; z-index:145; display:flex; align-items:flex-end; justify-content:center; background: color-mix(in srgb, var(--nv-void) 70%, transparent); backdrop-filter: blur(10px)`; onClick (backdrop) → `S.edit.close()` (this is what the back swipe's 'sheet' mode uses). Panel: `className="nv-liquid nv-liquid-thick nv-materialize"`, width 100%, max-width 560, `max-height: 86vh`, `border-radius: var(--nv-radius) var(--nv-radius) 0 0`, padding `0 16px calc(18px + env(safe-area-inset-bottom))`, `onClick` stopPropagation. Use `useSheetDrag(S.edit.close, { threshold: 80 })`: `ref={drag.sheetRef}` on the panel; the grab zone row (grabber centred, "Pinned" title 600 17px left, `Done` TextAction accent right → close) gets `{...drag.handleProps}` and is sticky like GlassSheet's.
- Rows: from `S.allCards` in order: `[toggle][label][drag handle ⠿]`, 52px tall, `.nv-sum-row`, a hairline between rows (`--nv-sum-sep`). Toggle = a native `<input type="checkbox" role="switch">` visually hidden under a `.nv-sum-switch` label (so it is a real control: keyboard + VoiceOver + the iOS haptic path); `checked = row.on`; change → `S.edit.setList(list with row.on flipped)`. A row whose card is not `present` still toggles (it is a preference) but shows `<Meta tone="faint">nothing to show today</Meta>` under its label.
- Drag: ONLY on the handle (`touch-action: none` there). Imperative, no React state per move (the useSheetDrag comment explains why): on pointerdown → `setPointerCapture`, measure every row's `getBoundingClientRect()` once, remember `fromIndex`, add class `drag` to the row; on pointermove → write `row.style.transform = translateY(dy)` on the dragged row directly; compute `toIndex` from the pointer's Y against the measured midpoints; for every other row set `style.transform` to `translateY(±rowHeight)` or `''` depending on whether it should shift up/down (rows have `transition: transform 180ms cubic-bezier(.32,.72,0,1)` so they slide; the dragged row has `transition: none`); when `toIndex` changes → `haptic('tick')`. On pointerup/cancel → clear all transforms, call `S.edit.setList(movePinned(list, fromIndex, toIndex))` ONCE, then release capture. Multi-touch: ignore a second pointer while one drag is live. Escape closes. Reduced motion: no slide transitions, still functional. The list re-renders behind the sheet as he edits (Home updates live).
